# Sprint_7 - API Tests for Yandex Samokat

## Описание проекта
Проект содержит автоматические тесты для API учебного сервиса Яндекс Самокат.

## Структура проекта
- `src/api/` - классы для работы с API
- `src/helpers/` - вспомогательные функции
- `src/data/` - тестовые данные
- `tests/` - тесты для различных ручек

## Тестируемые ручки

### Основное задание (4 ручки)
1. **Создание курьера** (`test_courier_create.py`) - 4 теста
2. **Логин курьера** (`test_courier_login.py`) - 5 тестов
3. **Создание заказа** (`test_order_create.py`) - 4 теста
4. **Список заказов** (`test_order_list.py`) - 1 тест

### Дополнительное задание (3 ручки)
5. **Удаление курьера** (`test_courier_delete.py`) - 3 теста
6. **Принятие заказа** (`test_order_accept.py`) - 4 теста
7. **Получение заказа по номеру** (`test_order_get.py`) - 7 тестов
